Peekthru

Privacy

Peekthru → Support →

Peekthru displays files you choose locally. It does not collect analytics, send file contents to a server, execute notebooks or source code, or download embedded document resources. Scientific formulas use bundled KaTeX assets in an isolated local renderer.

Recent files are stored as read-only security-scoped bookmarks in the app's local preferences. Use File → Open Recent → Clear Recent to remove them. Font and display preferences are also stored locally. HDF5 metadata caches and formula previews are held in memory and have fixed size limits.

Clicking an ordinary HTTP/HTTPS link explicitly opens your default browser; that browser and destination have their own privacy practices. If you send a support message, include only information you choose to share. Avoid sending private research data; a small synthetic reproduction is usually sufficient.
