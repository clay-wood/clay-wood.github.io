Peekthru

A local Mac viewer and Finder Quick Look extension for Python, Julia, Markdown, Jupyter notebooks, and HDF5. Peekthru works offline and does not execute code.

What it does

  • Finder Quick Look previews for .py, .jl, .md, .markdown, .ipynb, .h5, and .hdf5 files.
  • A native, read-only viewer with Find, adjustable text size, and recent files.
  • Python and Julia source with syntax highlighting.
  • Markdown with rendered formulas and a heading navigator.
  • Jupyter notebooks (nbformat 4), including saved text, images, and mathematical expressions.
  • HDF5 groups, dataset metadata, path search, and selected slices. Displayed values can be copied as TSV.
  • Local mathematical rendering. Reload is manual when a file changes.
  • Some HDF5 datatypes and compression filters are unsupported. Notebooks show saved outputs rather than interactive widgets, and previews use size limits.

Available now

Peekthru is available on the Mac App Store for $2.99. It requires macOS 14 or later and runs on Apple Silicon and Intel Macs. There is no subscription.
